# 英語版 README 作成の設計

## 目的

初学者向けに拡充した日本語 README と同じ情報を、自然で読みやすい英語で提供する。

## 対象と方針

- 新規作成するファイルはルートの `README.en.md` のみ。
- 英訳元は `docs/japanese-readme` ブランチの拡充版 `README.md`（PR #2）とする。
- 見出し構成、ポイント、サンプル一覧、前提条件、ビルド・テスト・実行手順、ディレクトリ構成、注意事項を英語で同じ順序・範囲に揃える。
- 逐語訳ではなく初学者に自然な英語を使う。プロジェクト名、パス、コマンド、数値、教師ラベルは変更しない。
- 日本語版、ソースコード、言語切替リンクは変更しない。

## 検証

英語版のコード例とパスが日本語版と一致し、全セクションが対応していることを確認する。Markdown のコードフェンスと差分を点検する。ドキュメントのみの追加なので、ビルドやテストは実行しない。
