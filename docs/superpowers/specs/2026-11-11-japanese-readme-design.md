# 日本語 README 更新の設計

## 目的

機械学習を学び始めた読者が、リポジトリの見どころをつかみ、各サンプルを自分の環境で実行できるようにする。

## 対象と構成

変更対象はルートの `README.md` のみ。初学者が試す順に、次の情報を日本語で整理する。

- リポジトリの目的と、同じ基礎概念を複数の実装・可視化で比較できる点
- C# のニューラルネットワーク、Python の座標分類、WPF のグラフ、ONNX Runtime の MNIST 推論の役割
- .NET 10、WPF 実行時の Windows 要件、Python サンプルの Matplotlib 依存
- ソリューションのビルドとテスト、および MNIST・Python・WPF の各実行手順
- 主要ディレクトリとサンプルデータ／モデルの位置
- 学習用サンプルであること、乱数初期化など結果の解釈に関する注意

実際のプロジェクト設定、ファイル配置、実行コードで確認できる内容だけを記述する。README の範囲を超えたコード変更、依存関係の追加、学習アルゴリズムの変更は行わない。

## 実行例の方針

- リポジトリルートから実行する .NET コマンドを PowerShell 形式で示す。
- WPF は Windows での実行に限定して案内する。
- Python スクリプトは CSV の相対パスに合わせて `NeuralNetwork.Python` を作業ディレクトリとして実行する。Matplotlib の導入方法も案内する。
- ノートブックは対応する Python 環境で開き、セルを実行する手順を補足する。
- 特定の正解出力や精度を保証せず、サンプルの目的と制約を説明する。

## 検証

コマンドとファイルパスが実在することを確認し、README のリンク・Markdown と差分を点検する。ドキュメントのみの変更のため、ビルドやテストは実行しない。
