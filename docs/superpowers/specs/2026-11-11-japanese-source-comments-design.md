# 日本語コメント整備の設計

## 目的

リポジトリ内のソースを初見でも追いやすくするため、処理の目的、データの流れ、学習計算の要点を日本語コメントで補う。既存の英語コメントは同じ意図の日本語に置き換える。

## 対象と方針

- C#、Python、XAML、および Python ノートブックのコードセルを対象とする。
- テストコードにも、テストが確認する振る舞いを理解するために必要なコメントを付ける。
- 自明な行の逐語説明は避け、処理のまとまり、数式、データ形式や変換など、理解に役立つ箇所に限定する。
- コメントアウトされた既存コードは削除せず、そのまま残す。
- コメント以外のコード、文字列、データ、UI 表示は変更しない。

## 検証

差分を確認し、コメント以外の実行コードに変更がないことを確認する。コメント変更後に既存の .NET テストを実行し、動作への影響がないことを確認する。
